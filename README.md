# A+ Core 1 Study Companion

Use these materials alongside the **220-1201 Core 1** practice tests. They help you turn an answer review into a practical study plan; they do not contain the question bank or reproduce certification exam questions.

## Start here

- Read `STUDY-GUIDE.md` for a workable study and review routine.
- Open `index.html` in a browser for a printable copy of the guide.
- Download `review-journal.csv` and keep a short record of the decisions you want to revisit.
- Use `OFFICIAL-READING.md` and the reference links attached to individual questions to check the underlying behavior.
- Download the companion ZIP if you prefer to keep the files together offline. `SHA256SUMS.txt` lists their checksums.

The practice setting is 90 minutes per 90-question form. An 80% result is a study benchmark, not a conversion to CompTIA's scaled passing score. These fixed questions do not reproduce the certification exam's performance-based tasks.

This is independent preparation, not an official CompTIA product or endorsement. Check the certification provider for the current exam objectives and policies before booking an exam. This companion covers Core 1, not Core 2.
